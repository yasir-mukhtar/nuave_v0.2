# Measurement crosswalk

This is the review rubric for comparing v3 text with the prior ten-purpose instrument. It is not a claim of longitudinal equivalence.

| Old purpose | Preserved when final text asks for | Partial when | Changed when | Unsupported when |
|---|---|---|---|---|
| Category discovery | options in the category/context | asks only about one business | gives advice without options | no discovery request exists |
| Situation | a real occasion that leads someone to look | occasion is implied but incomplete | replaces situation with generic need | no situation evidence |
| Need fit | whether options suit a supplied need | asks a property without suitability | changes the need or target | unsupported need |
| Offering use case | one supported offering/use case | category-only question | different offering/decision | offering invented or absent |
| Shortlist | multiple realistic options to consider | names only one option | substitutes recommendation | no options requested |
| Open comparison | comparison among unnamed realistic options | asks for a list with no comparison | names the business or comparator | no comparison |
| Brand fit | named business against a stated supported need | evaluates a property only | changes the need or scope | business not named where required |
| Explicit recommendation | directly asks whether to recommend the named business | asks “good or not” without advice | asks only for properties | no recommendation request |
| Direct comparison | named business versus supplied/accepted target and relation | mentions alternatives without relation | target or relation changes | target absent |
| Conditional fit/misfit/trade-offs | who it suits, who it does not, or trade-offs | one-sided suitability | becomes generic evaluation | no conditional evidence |

Reviewers mark each old purpose as **preserved**, **partial**, **changed**, or **unsupported**, citing the final question index and the supporting brief evidence. Do not infer preservation from a tag.
