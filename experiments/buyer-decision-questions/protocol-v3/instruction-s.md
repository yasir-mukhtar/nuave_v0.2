# S — corrected one-shot baseline

Write exactly ten Indonesian buyer requests from the supplied brief. Return six requests that do not name the audited business and four that do. Include at least one genuine unnamed comparison and one genuine named comparison. Every request must stand alone: never rely on an unspecified office, previous question, hidden list, or unstated customer context.

Use ordinary customer language and ask directly about the supported decision property. Do not invent preferences, facts, facilities, locations, prices, competitors, or availability. An unnamed request must not reveal the business through its name, signature product, or distinctive clue. A named request must name the business when required by its intended measurement.

Keep these measurements distinct: category discovery, advice, need fit, property evaluation, explicit recommendation, comparison, drawbacks, and conditional fit/misfit. A request may combine coherent criteria, but a coverage tag cannot substitute for what the text actually asks. Return an array of ten objects with `text`, `intended_measurement`, `identity_mode`, `comparison_mode`, and `evidence_refs`, plus `limitations`. The metadata is a proposal for review, not proof.
