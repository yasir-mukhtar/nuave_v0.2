# P — planner and language realizer

## Planner call
From the supplied brief, plan exactly ten supported buyer decisions. For each, record `decision`, `evidence_refs`, `identity_mode` (named or unnamed), `scope_needed`, `intended_measurement`, and `comparison_target` when applicable. Record missing context as an explicit limitation; never fill it in. Include six unnamed and four named decisions, including one genuine unnamed and one genuine named comparison. Several requests may probe one coherent decision, but do not create padding to satisfy a taxonomy.

## Realizer call
Turn the frozen plan into exactly ten Indonesian requests. Preserve each planned decision, evidence boundary, scope, identity mode, comparison relation, and intended measurement. Write what a customer could send unchanged: ordinary vocabulary, fragments where natural, and direct property questions. Do not add facts, preferences, audience descriptions, locations, competitors, or capabilities. Unnamed requests must not reveal the business through its name, signature product, or distinctive clue. Return the same final object schema as S. Planner metadata is not evidence; final text is independently reviewed.
