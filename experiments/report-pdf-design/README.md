- `reference.pdf`: 33 pages, 16:9 (1440 × 810 points), each page an image of
  one Figma frame at 1.5× resolution. Text in it cannot be selected; it is a
  picture of the design, not the product PDF.

Where this reference and a spec disagree, the spec wins (D-4). It is not
served by the app and nothing reads it at run time.

## What the pages hold

- **Pages 1 to 24:** cover, contents, how to read the report, the summary,
  sections 01 to 04 with their dividers, Bahan siap pakai, Lembar Kerja,
  Penutup, and the Lampiran divider. Page numbers follow the frame names in
  the Figma.
- **Pages 25 to 32:** the appendix, an index (A0) and sample answer pages
  for the likely cases:
  - a question asked three times;
  - a long answer with a table and its continued page;
  - an ordinary answer;
  - Google without an AI Overview;
  - an answer that names no clinic;
  - no search volume, no cited sources and a failed check.
- **Page 33:** the back cover.

## Limits

- **The data is invented,** from the Report v3 proof of concept A ("Ultima
  Clinic", `.example` sites, PR #205). The A5 "no clinic named" and A8
  pages change that data on purpose, to show the case.
- **Only some pages show real data today.** Several pages draw sections that
  need a Report v3 package first: Cek fakta, Kata AI vs Menurut Anda,
  Halaman mereka, Situs yang dibaca AI, Untuk tim web Anda, Bahan siap pakai,
  Lembar Kerja and the playbook tags. The plan's §5.2 says which pages
  today's saved data can fill.
- **Only two Langkah pages are drawn.** The PDF gets one per recommendation:
  page 19 shows the full v3 version and page 20 the version with today's
  data.
